# Worktree lifecycle

Compatibility entry for existing personal host instructions. The maintained
[workspace guide](../workflows/start-task.md) covers selection, delegation,
creation, verification and retention. Read its selection section before choosing
a local development session; enter creation only when actually requested.

Editor preferences belong to an explicitly selected personal profile, not
workspace readiness. Accessibility PR evidence belongs to the selected specialist
guidance, not the generic workspace lifecycle. Existing personal requirements
remain applicable through the current user's trusted profile/instructions.
