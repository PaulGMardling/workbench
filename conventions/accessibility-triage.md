# Accessibility triage

Optional specialist route, required when selected by the current task or
trusted personal/repository policy. Read
[Fluent accessibility diagnosis](../skills/fluent-a11y-diagnosis/SKILL.md) and its
stage-specific references before a full run. Explicit file loading works without
installing/registering a skill.

Establish whether each claim is a real accessibility defect and the right fix
layer, using W3C WAI as the primary standards reference. A reproduction is not
automatically a defect; failed reproduction is not proof of no defect.
Keep diagnosis, approved remediation and verification separate.

For selected PR reproduction/readiness requirements, read
[runnable PR evidence](../skills/fluent-a11y-diagnosis/references/pr-evidence.md).
Those requirements are not part of generic workspace selection.
Load applicable private evidence/account/setup overlays only in authorised
personal context. Missing required guidance blocks dependent work.

Diagnosis/audit alone does not authorise fixes or publication. Apply the current
user's explicit scope and any separately selected standing delivery authority;
do not make an already authorised publisher repeatedly request commit/push.
This pointer grants no access, comments, ticket disposition changes or cleanup.
Keep individual tickets, conversations and task history out of the portable skill.
